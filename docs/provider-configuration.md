# Provider configuration

AI, translation, and text-to-speech providers are configured by the user. Use only credentials and endpoints that you control or are authorized to use.

- OpenAI-compatible providers use the endpoint and API key configured in the app.
- DeepL, Google, Microsoft, Aliyun, Azure, and OpenAI TTS settings use the provider's own API terms and quotas.
- Never commit API keys, cookies, private URLs, or provisioning material.

This document will receive platform-specific screenshots and troubleshooting guidance as the independent UI is redesigned.
