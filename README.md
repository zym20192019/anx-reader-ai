# Anx Reader AI

An independent Anx Reader project focused on a clean, AI-first reading workspace and future UI redesign.

This repository starts from a verified Anx Reader beta snapshot, with a flattened Git history. It is maintained separately from the upstream repository and the earlier integration Fork.

## Current foundation

- Flutter multi-platform reader foundation
- Chat Completions + tools/function calling Agent architecture
- Central AI Workspace / AI 问书吧
- Read-only workspace overview for books, reading history, and notes
- Explicit confirmation metadata for data-mutating AI plans
- Android application identity: `com.zym20192019.anxreader`
- Android display name: `Anx Reader AI`

## Direction

The next phase will separate the product UI and release infrastructure from upstream assumptions, then iterate on navigation, visual language, and the Workspace Agent experience.
